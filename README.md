MyVault – Web-Based Cloud File Management System

MyVault is a lightweight cloud-style file management system that allows users to upload, browse, and download files through a web interface. The project is built using Go for the backend and HTML/JavaScript for the frontend, focusing on core system and backend concepts.

Features

> Upload files and create folders via REST APIs
> Browse files and directories using a web-based file explorer
> Download files directly from the server
> Dynamic folder navigation using hierarchical JSON data
> User-isolated server-side file storage
